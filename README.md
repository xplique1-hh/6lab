# Домашнее задание к работе 6

## Условие задачи
Составить программу, которая проверяет, принадлежит ли заданная пользователем точка с координатами (x, y) заданным закрашенным (заштрихованным) областям, показанным на рисунке, и выводит на экран сообщение.

**Контрольный пример:**
- Точка `(0, 0)` — не принадлежит области.
- Точка `(1.5, 3)` — принадлежит области (верхний прямоугольник).
- Точка `(0, -3)` — принадлежит области (нижний прямоугольник).

## 1. Алгоритм

### Алгоритм
1. **Начало**
2. Ввести координаты точки `x` и `y`.
3. Проверить условие принадлежности точке одной из трех областей:
   - Верхняя область: `x >= -1 && x <= 2 && y >= -5 && y <= 5`
   - Средняя область: `x >= -5 && x <= -1 && y >= -5 && y <= -2`
   - Правая область: `x >= 2 && x <= 6 && y >= 2 && y <= 5`
4. Если условие истинно — вывести «Точка принадлежит области».
5. Иначе — вывести «Точка не принадлежит области».
6. **Конец**

## 2. Реализация программы

```c
#include <stdio.h>
#include <math.h>
#include <locale.h>

int main() {
    setlocale(LC_ALL, "RUS");
    float x, y;

    printf("Введите координаты x и y: ");
    scanf("%f %f", &x, &y);

    if ((x >= -1 && x <= 2 && y >= -5 && y <= 5) || (x >= -5 && x <= -1 && y >= -5 && y <= -2) || (x >= 2 && x <= 6 && y >= 2 && y <= 5)) {
        printf("Точка принадлежит области");
    }
    else {
        printf("Точка не принадлежит области");
    }

    return 0;
}
```
